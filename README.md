# FM_Templates

Website templates library in Roman English — open `index.html` in a browser to browse, preview and download templates.

## What is inside

171 templates in 7 categories:

- Sirf HTML — 13
- HTML + CSS — 24
- HTML + CSS + JS — 25
- Animations — 28
- Full Projects — 17
- Full Websites — 52
- PHP — 12

## Features

- Live Preview with Desktop (Full), Tablet (768px) and Mobile (390px) sizes, in-page and in a new tab
- Download each template as a complete `.html` file (PHP templates download as `.php`)
- Search, category filters and Recommended / Name A–Z sort
- Favourites (saved in the same browser/device), Learning Path, Dark / Light theme
- Fully responsive, Roman English only
- Feedback form (sends via the visitor's own email app)

## How to use

1. Open `index.html` in any modern browser.
2. Pick a category, open a template, preview it in different sizes.
3. Download the template and practise by editing it.

PHP templates do not run directly in the browser — put the downloaded `.php` file in XAMPP `htdocs` to run it.
